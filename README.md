## 📌 Descrição do Projeto
O **TaskTracker** é uma aplicação em linha de comando (CLI) desenvolvida em Python para centralizar e organizar tarefas diárias. O sistema permite o cadastro de pendências com validação estrita de dados, atualizar os dados ou o status de uma tarefa existente, remover permanentemente uma tarefa da lista com base no seu número, e a visualização clara de tarefas gravadas, garantindo o controlo de prioridades e datas limite.
